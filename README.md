# dotbin

> A collection of personal shell utilities, each designed to perform a single function.

These scripts are standalone and are designed to be stored in `~/.local/bin`.

## Installation

Install a single script:

```bash
curl -fsSL https://raw.githubusercontent.com/garpra/dotbin/main/<script-name> -o ~/.local/bin/<script-name>
chmod +x ~/.local/bin/<script-name>
```

Or clone the repo and symlink what you need:

```bash
git clone https://github.com/garpra/dotbin.git
ln -s ~/dotbin/<script-name> ~/.local/bin/<script-name>
chmod +x ~/.local/bin/<script-name>
```
